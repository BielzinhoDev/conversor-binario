# Conversor Binário  

Projeto em Node.js e Express para conversão de números decimais em binário e hexadecimal, com persistência em MySQL.  

## 🧩 Evolução por Unidades  
- Unidade 1: Add conversion from decimal to hexadecimal  
- Unidade 2: Implementação - TDD com Nodejs  
- Unidade 3: API de Conversão, Testes e documentação  
- Unidade 4: Configuração de CI/CD com Jenkins  
- Unidade 5: Integração com MySQL  

## 1. Instalação 🚀  
Clone o repositório e instale as dependências:  
```bash
git clone https://github.com/BielzinhoDev/conversor-binario.git
cd conversor-binario
npm install
```

### 2. Execução ▶️
```markdown
## Execução
Inicie o servidor com:

```bash
node index.js
## Acesse em: http://localhost:3000 (localhost in Bing)
```

### 3. Rotas disponíveis  🌐 
```markdown
## Rotas disponíveis
- `/to-hex/:decimal` → converte decimal para hexadecimal
- `/to-binary/:decimal` → converte decimal para binário e salva no MySQL
```
